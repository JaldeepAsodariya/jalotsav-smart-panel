FC26 Node Tester

Talks to the two ESP32-C3 nodes over Bluetooth Low Energy, straight from the browser. No app, no Wi-Fi network, no passwords.

This browser has no Web Bluetooth. Use Chrome or Edge on a Mac, Windows or Android, and open the page from http://localhost (see the README). Safari and Firefox don't support it. The Simulate buttons still work.
