FC26 Build Guide

FlutterCon India 2026 smart-home demo: two ESP32-C3 Super Mini nodes and one Flutter display app, Jalotsav Panel. Node 1 measures a PT100. Node 2 sounds a 220V hooter when it gets too hot. The display shows it all over Bluetooth. Everything you need is on this page: wiring, setup, tests, the app and the full firmware.

How it works

 Node 1 (PT100) ──Wi-Fi FC26-NET, UDP 1×/s──▶ Node 2 (siren, access point): decides the alarm, drives the hooter
      │                                   │
      │ BLE: temperature                  │ BLE: alarm state, Acknowledge, Test, limits
      ▼                                   ▼
   Display: Jalotsav Panel (Flutter)
     main:   Raspberry Pi + touchscreen
     backup: phone / tablet / Mac  (or ble-test.html in Chrome)
  • Node 2 makes its own Wi-Fi network, no router. Node 2 is an access point called FC26-NET (password fc26-panel, channel 1, 192.168.4.1). Node 1 joins it and sends one UDP packet a second to port 4626, and rejoins by itself if Node 2 reboots. Node 2 only accepts packets that start with FC26 and carry the same NETWORK_ID.
  • Wi-Fi power is 8.5 dBm on purpose. ESP32-C3 Super Mini antennas are poorly matched; at full power their Wi-Fi often doesn't get out at all. Don't raise FC26_WIFI_TX_POWER.
  • Node 2 is the brain, so the alarm works with no phone or laptop around:
    • temperature ≥ setpoint for delay seconds → ALARM, hooter ON
    • touch the TTP223 → ACKNOWLEDGED, hooter OFF (stays off until it cools)
    • temperature ≤ setpoint − hysteresis → back to NORMAL by itself
    • hold the TTP223 for 2 s while normal → 2-second hooter test
    • Node 1 silent for 6 s, or reporting a probe fault → hooter OFF, LED blinks blue
    • hooter ON for 2 minutes → silences itself
  • BLE is for watching and settings. The display app connects to both nodes: Node 1 (FC26-TEMP) for the temperature, Node 2 (FC26-SIREN) for the alarm, the hooter and the limits. The alarm runs on Node 2, so it works with the display off. Each board takes one BLE connection: close the app before using the test page.

Defaults: setpoint 35 °C, hysteresis 2 °C (clears at 33 °C), delay 3 s.

The display: Jalotsav Panel

One Flutter app, Jalotsav Panel (Application/jalotsav_panel, ID com.jalotsav.smartpanel), is the display:

  • Main display: Raspberry Pi with a touchscreen, running the app through flutter-pi.
  • Backup display: a phone or tablet (Android, iOS) or a Mac, running the same app. Same screens, same Bluetooth links.

What it does:

  • Connects to both nodes by itself: FC26-TEMP for the temperature (the main source) and FC26-SIREN for the alarm, the hooter and the limits. No pairing. The two dots in the top bar turn green when each board is linked.
  • Live: temperature gauge, alarm state (Normal / Rising / Alarm / Acknowledged), siren card with Acknowledge and Test siren, last 60 s chart. Trend and Alarms show history.
  • Settings: setpoint, hysteresis and delay (saved on Node 2), PT100 calibration (set the real temperature with ± buttons, tap Calibrate; saved on Node 1), and light/dark theme.
  • Backup siren on the display: if Node 2 isn't linked, the app applies the same alarm rules to Node 1's readings and sounds an alarm itself (Android alarm volume). Acknowledge silences it; it stops when the probe cools or when Node 2 links and takes over. Limits changed while Node 2 is offline aren't saved.
  • One display at a time: each board takes one Bluetooth connection, so close the app on one device (or the test page) before connecting another.

2N2222 legs: most TO-92 parts (PN2222A) are E-B-C with the flat face toward you, legs down, but some (P2N2222A) are C-B-E. Check yours with a multimeter's diode mode: the base is the leg that reads ~0.6 V to both other legs (red probe on base).

Bare relay pins (SRD-05VDC-SL-C style): two coil pins, plus COM, NO and NC. Find the coil with a multimeter (~70 Ω between the two coil pins). Check the contact rating printed on the relay: it must be at least 250 VAC and more than the hooter's current.

⚠️ 220V: read before wiring either node

  • Switch the live (L) wire through the relay, never neutral. Use COM → NO, so the hooter is silent whenever the board is off or rebooting.
  • A 1 A fuse on live, before anything else, on each node. Node 1: mains L → fuse → Hi-Link AC L; mains N → Hi-Link AC N. Node 2: mains L → fuse, then from the fused side to both the Hi-Link AC L and the relay COM; mains N → Hi-Link AC N and the hooter.
  • Everything that touches 220V (Hi-Link input pins, relay contacts, fuse, hooter terminals) goes inside a closed plastic box. Use strain relief on the mains lead. Keep mains tracks/wires ≥ 6 mm away from the low-voltage side. If the hooter has a metal body or an earth terminal, connect it to mains earth.
  • Never connect USB while the board is on mains. Flash the firmware first with USB only, then unplug USB, then plug in mains.
  • Bench-test Node 2 with a bulb in place of the hooter first. Ask the venue whether a mains device on stage is allowed, and keep the plug within reach.

Arduino IDE setup (once)

  1. Boards Manager → install "esp32" by Espressif Systems (3.x).
  2. Library Manager → install "Adafruit ADS1X15" (Node 1 only; accept Adafruit BusIO). Node 2 needs no extra libraries.
  3. Tools menu, for both boards:
    • Board: ESP32C3 Dev Module
    • USB CDC On Boot: Enabled. Without it, Serial Monitor stays empty.
    • Partition Scheme: Huge APP (3MB No OTA/1MB SPIFFS). BLE + Wi-Fi is ~1.27 MB, right at the edge of the default partition.
  4. Make one sketch folder per node. Each folder needs its .ino and a copy of fc26_protocol.h (download buttons at the bottom of this page).
  5. If an upload won't start: hold BOOT, tap RESET, release BOOT, then upload again.

Built with esp32 core 3.3.12 (BLE on the NimBLE backend) and Adafruit ADS1X15 2.6.2, no warnings. Tested on hardware: Node 1 (PT100, ADS1115, BLE to the app, calibration from the app) and the app's backup siren. Node 2 is compile-tested; its hardware is in progress.

Before the first power-up

  • Node 1: measure the reference resistor with a multimeter and put the value in RREF at the top of the sketch (e.g. 987.0).
  • Flash with USB only, mains unplugged. Never have USB and the Hi-Link connected at the same time.
  • Two kits in one room? Give each kit its own NETWORK_ID in fc26_protocol.h, the same in both folders.

First test with Serial Monitor (115200 baud)

  1. Flash Node 2 first. Serial shows [wifi] access point FC26-NET up; its LED blinks blue until Node 1 joins.
  2. Flash Node 1. Serial shows [wifi] joined FC26-NET, then [temp] 27.84 °C (110.85 Ω, offset +0.00) every second. Hold the probe: it rises.
  3. Node 2's LED turns green and its Serial shows [sensor] Node 1 online, then every 10 s 1 device(s) on FC26-NET, N packets from Node 1.
  4. Bench-test the relay with a bulb, not the hooter: hold the TTP223 for 2 s and the bulb comes on for 2 s.
  5. Run the full flow with the default 35 °C setpoint: warm the probe (hand, warm water or a lighter held well away), wait 3 s → bulb on; touch the TTP223 → off; let it cool below 33 °C → back to green. If Node 2 kept an older saved setpoint, set 35 °C in the app's Settings.

BLE contract

Little-endian. Temperatures are °C × 100 as int16; -32768 = no reading. All UUIDs end in -6a1b-4d2e-9f3c-8b5e7a0c1d2f.

/*
 * FlutterCon India 2026: Node 1, temperature
 * ESP32-C3 Super Mini + ADS1115 + PT100
 *
 * Measures the PT100 with the ADS1115 (ratiometric) once a second and:
 *   - joins Node 2's Wi-Fi network "FC26-NET" and sends it °C as one UDP packet a second
 *     (no router: Node 2 is the access point)
 *   - serves it over BLE as "FC26-TEMP" (the app reads the temperature here and calibrates)
 *
 * Circuit (see ../WIRING.md):
 *   3V3 ── A0 ── Rref ── A1 ── lead A ──┐
 *                                       PT100 ── lead C ── GND
 *                         A2 ── lead B ──┘   (lead B is the sense wire: no current flows)
 *
 * Board: "ESP32C3 Dev Module", USB CDC On Boot: Enabled, Partition: Huge APP (3MB No OTA)
 * Library: "Adafruit ADS1X15"
 */

#include <Wire.h>
#include <WiFi.h>
#include <WiFiUdp.h>
#include <Preferences.h>
#include <Adafruit_ADS1X15.h>
#include <BLEDevice.h>
#include <BLEServer.h>

#include "fc26_protocol.h"

struct Measurement { fc26::Fault fault; float ohms; float celsius; };

// ---------- Pins (ESP32-C3 Super Mini) ----------
constexpr int PIN_SDA   = 5;   // right header
constexpr int PIN_SCL   = 6;

// ---------- PT100 measurement ----------
constexpr float RREF  = 980.0f;  // ohms. Measure YOUR resistor with a multimeter and put the value here.
constexpr float R0    = 100.0f;   // PT100 = 100 Ω at 0 °C
constexpr int   WIRES = 2;        // 3 = lead compensation via A2; 2 = 2-wire probe (A2 unused)
constexpr int   SAMPLES = 4;      // conversions averaged per channel
constexpr uint32_t READ_EVERY_MS = 1000;


Adafruit_ADS1115 ads;
Preferences prefs;
bool adsOk = false;
float offsetC = 0;           // calibration offset, stored in flash
float lastRawC = NAN;        // before offset, used by "CAL="
uint8_t seq = 0;

BLECharacteristic *readingChr = nullptr;
volatile bool bleConnected = false;
portMUX_TYPE cmdMux = portMUX_INITIALIZER_UNLOCKED;
char pendingCmd[24] = {0};

WiFiUDP udp;
const IPAddress NODE2(fc26::NODE2_IP[0], fc26::NODE2_IP[1], fc26::NODE2_IP[2], fc26::NODE2_IP[3]);
uint32_t sentOk = 0, sentFail = 0;

// ---------- PT100 maths ----------
// Callendar–Van Dusen (IEC 60751), solved for t ≥ 0 °C; within 0.1 °C down to −40 °C.
float ohmsToCelsius(float r) {
  constexpr float A = 3.9083e-3f, B = -5.775e-7f;
  const float disc = A * A - 4 * B * (1 - r / R0);
  return (-A + sqrtf(disc)) / (2 * B);
}

// Reads one input in volts, choosing the most sensitive ADS1115 range that fits.
float readVolts(uint8_t ch) {
  struct Range { adsGain_t gain; float fullScale; };
  static const Range ranges[] = {
    {GAIN_SIXTEEN, 0.256f}, {GAIN_EIGHT, 0.512f}, {GAIN_FOUR, 1.024f},
    {GAIN_TWO, 2.048f}, {GAIN_ONE, 4.096f},
  };
  ads.setGain(GAIN_ONE);
  const float coarse = ads.computeVolts(ads.readADC_SingleEnded(ch));
  for (const Range &r : ranges) {
    if (fabsf(coarse) < r.fullScale * 0.9f || r.gain == GAIN_ONE) {
      ads.setGain(r.gain);
      float sum = 0;
      for (int i = 0; i < SAMPLES; ++i) sum += ads.computeVolts(ads.readADC_SingleEnded(ch));
      return sum / SAMPLES;
    }
  }
  return coarse;
}

Measurement measure() {
  if (!adsOk) return {fc26::FAULT_ADC_MISSING, NAN, NAN};
  const float v0 = readVolts(0);              // top of Rref (3V3 rail)
  const float v1 = readVolts(1);              // bottom of Rref = lead A
  const float v2 = WIRES == 3 ? readVolts(2) : v1;  // sense lead B
  const float vRef = v0 - v1;                 // volts across Rref → current
  if (v0 < 2.5f) return {fc26::FAULT_ADC_MISSING, NAN, NAN};   // A0 not wired to 3V3
  if (vRef < 0.02f) return {fc26::FAULT_OPEN, NAN, NAN};      // almost no current: probe open
  if (v2 > v1 + 0.005f || v2 < -0.005f) return {fc26::FAULT_OPEN, NAN, NAN};  // sense wire loose
  const float vElement = WIRES == 3 ? 2 * v2 - v1 : v1;       // lead resistances cancel
  const float ohms = RREF * vElement / vRef;
  if (ohms < 10.0f) return {fc26::FAULT_SHORT, ohms, NAN};
  if (ohms < 18.0f || ohms > 390.0f) return {fc26::FAULT_RANGE, ohms, NAN};
  return {fc26::FAULT_NONE, ohms, ohmsToCelsius(ohms)};
}

// ---------- BLE ----------
class ServerCallbacks : public BLEServerCallbacks {
  void onConnect(BLEServer *) override { bleConnected = true; }
  void onDisconnect(BLEServer *) override {
    bleConnected = false;
    BLEDevice::startAdvertising();   // let the next client in
  }
};

class CommandCallbacks : public BLECharacteristicCallbacks {
  void onWrite(BLECharacteristic *c) override {
    String v = c->getValue();
    portENTER_CRITICAL(&cmdMux);
    strlcpy(pendingCmd, v.c_str(), sizeof(pendingCmd));
    portEXIT_CRITICAL(&cmdMux);
  }
};

void setupBle() {
  BLEDevice::init("FC26-TEMP");
  BLEServer *server = BLEDevice::createServer();
  server->setCallbacks(new ServerCallbacks());
  BLEService *svc = server->createService(FC26_TEMP_SERVICE);
  readingChr = svc->createCharacteristic(
      FC26_TEMP_READING, BLECharacteristic::PROPERTY_READ | BLECharacteristic::PROPERTY_NOTIFY);
  BLECharacteristic *cmd = svc->createCharacteristic(
      FC26_TEMP_COMMAND, BLECharacteristic::PROPERTY_WRITE | BLECharacteristic::PROPERTY_WRITE_NR);
  cmd->setCallbacks(new CommandCallbacks());
  svc->start();
  BLEAdvertising *adv = BLEDevice::getAdvertising();
  adv->addServiceUUID(FC26_TEMP_SERVICE);
  adv->setScanResponse(true);
  BLEDevice::startAdvertising();
}

void handleCommand() {
  char cmd[sizeof(pendingCmd)];
  portENTER_CRITICAL(&cmdMux);
  strlcpy(cmd, pendingCmd, sizeof(cmd));
  pendingCmd[0] = 0;
  portEXIT_CRITICAL(&cmdMux);
  if (!cmd[0]) return;

  if (!strncmp(cmd, "OFS=", 4)) {          // set the offset directly
    offsetC = constrain(atof(cmd + 4), -10.0f, 10.0f);
  } else if (!strncmp(cmd, "CAL=", 4)) {   // "the real temperature is X": offset = X − raw
    if (isnan(lastRawC)) { Serial.println("[cal] no valid reading yet"); return; }
    offsetC = constrain(atof(cmd + 4) - lastRawC, -10.0f, 10.0f);
  } else {
    Serial.printf("[ble] unknown command '%s'\n", cmd);
    return;
  }
  prefs.putFloat("ofs", offsetC);
  Serial.printf("[cal] offset now %+.2f °C\n", offsetC);
}

// ---------- Wi-Fi (join Node 2's network) ----------
void setupWifi() {
  WiFi.mode(WIFI_STA);
  WiFi.setTxPower(FC26_WIFI_TX_POWER);
  WiFi.setAutoReconnect(true);
  WiFi.begin(fc26::WIFI_SSID, fc26::WIFI_PASS, fc26::WIFI_CHANNEL);
  WiFi.setTxPower(FC26_WIFI_TX_POWER);
  Serial.printf("[wifi] joining %s\n", fc26::WIFI_SSID);
}

// Logs joins and drops, and retries if Node 2 wasn't up yet (or rebooted).
void handleWifi() {
  static bool wasUp = false;
  static uint32_t lastTry = 0, lastStats = 0;
  const bool up = WiFi.status() == WL_CONNECTED;
  if (up != wasUp) {
    wasUp = up;
    if (up) Serial.printf("[wifi] joined %s, IP %s, sending to %s:%u\n", fc26::WIFI_SSID,
                          WiFi.localIP().toString().c_str(), NODE2.toString().c_str(), fc26::UDP_PORT);
    else Serial.printf("[wifi] lost %s, looking again\n", fc26::WIFI_SSID);
    lastTry = millis();
  }
  if (!up && millis() - lastTry >= 10000) {
    lastTry = millis();
    Serial.printf("[wifi] %s not found yet (is Node 2 on?), retrying\n", fc26::WIFI_SSID);
    WiFi.disconnect();
    delay(100);   // let the old attempt stop, or begin() is refused ("sta is connecting")
    WiFi.begin(fc26::WIFI_SSID, fc26::WIFI_PASS, fc26::WIFI_CHANNEL);
    WiFi.setTxPower(FC26_WIFI_TX_POWER);
  }
  if (millis() - lastStats >= 10000) {
    lastStats = millis();
    Serial.printf("[wifi] %s, sent %lu ok, %lu failed\n", up ? "linked" : "not linked",
                  (unsigned long)sentOk, (unsigned long)sentFail);
  }
}

void sendToNode2(const fc26::TempPacket &pkt) {
  if (WiFi.status() != WL_CONNECTED) return;
  const bool ok = udp.beginPacket(NODE2, fc26::UDP_PORT) &&
                  udp.write((const uint8_t *)&pkt, sizeof(pkt)) == sizeof(pkt) && udp.endPacket();
  ok ? sentOk++ : sentFail++;
}

void publish(const Measurement &m) {
  int16_t centi = fc26::NO_READING;
  if (m.fault == fc26::FAULT_NONE) centi = (int16_t)lroundf((m.celsius + offsetC) * 100);

  fc26::TempPacket pkt = {{'F', 'C', '2', '6'}, fc26::VERSION, fc26::NETWORK_ID, seq, m.fault, centi};
  sendToNode2(pkt);

  // BLE reading: int16 centi-°C, uint16 centi-ohms, uint8 fault, uint8 seq, int16 centi-°C offset
  uint8_t b[8];
  const uint16_t centiOhms = isnan(m.ohms) ? 0 : (uint16_t)constrain(lroundf(m.ohms * 100), 0L, 65535L);
  const int16_t centiOfs = (int16_t)lroundf(offsetC * 100);
  memcpy(b, &centi, 2);
  memcpy(b + 2, &centiOhms, 2);
  b[4] = m.fault;
  b[5] = seq;
  memcpy(b + 6, &centiOfs, 2);
  readingChr->setValue(b, sizeof(b));
  if (bleConnected) readingChr->notify();
  seq++;
}

// ---------- Arduino ----------
void setup() {
  Serial.begin(115200);
  prefs.begin("fc26n1");
  offsetC = prefs.getFloat("ofs", 0);

  Wire.begin(PIN_SDA, PIN_SCL);
  adsOk = ads.begin(0x48, &Wire);
  ads.setDataRate(RATE_ADS1115_128SPS);
  Serial.printf("\nNode 1 (temperature) starting. ADS1115 %s, offset %+.2f °C\n",
                adsOk ? "found" : "NOT FOUND (check SDA/SCL/ADDR)", offsetC);

  setupWifi();
  setupBle();
}

void loop() {
  static uint32_t lastRead = 0;
  handleCommand();
  handleWifi();

  if (millis() - lastRead >= READ_EVERY_MS) {
    lastRead = millis();
    if (!adsOk) adsOk = ads.begin(0x48, &Wire);   // recover if the ADS was plugged in late
    const Measurement m = measure();
    lastRawC = m.fault == fc26::FAULT_NONE ? m.celsius : NAN;
    publish(m);
    if (m.fault == fc26::FAULT_NONE) {
      Serial.printf("[temp] %.2f °C  (%.2f Ω, offset %+.2f)\n", m.celsius + offsetC, m.ohms, offsetC);
    } else {
      Serial.printf("[temp] fault %u  (%.2f Ω)\n", m.fault, m.ohms);
    }
  }

}

/*
 * FlutterCon India 2026: Node 2, siren (the brain of the demo)
 * ESP32-C3 Super Mini + 5V relay (2N2222 driver, 1N4007 flyback) + TTP223 touch + common-anode RGB LED
 * + 220V hooter
 *
 * The alarm decision lives HERE, so the demo works with no app and no laptop:
 *   - creates the Wi-Fi network "FC26-NET" (no router needed); Node 1 joins it and sends °C
 *     as one UDP packet a second
 *   - temp ≥ setpoint for `delay` seconds  → ALARM, hooter ON
 *   - touch the TTP223                      → ACKNOWLEDGED, hooter OFF (stays off until it cools)
 *   - temp ≤ setpoint − hysteresis          → back to NORMAL automatically, hooter OFF
 *   - hold the TTP223 for 2 s when normal   → 2-second siren test
 *   - serves state + accepts commands over BLE as "FC26-SIREN" (test page and Flutter app)
 *
 * Board: "ESP32C3 Dev Module", USB CDC On Boot: Enabled, Partition: Huge APP (3MB No OTA)
 * Libraries: none beyond the esp32 core.
 * Wiring: see ../WIRING.md  —  ⚠️ 220V: read the mains section before wiring.
 */

#include <WiFi.h>
#include <WiFiUdp.h>
#include <Preferences.h>
#include <BLEDevice.h>
#include <BLEServer.h>

#include "fc26_protocol.h"

// ---------- Pins (ESP32-C3 Super Mini) ----------
constexpr int PIN_TOUCH = 5;    // right header. TTP223 I/O (active HIGH, momentary: jumpers A and B open)
constexpr int PIN_RELAY = 10;   // right header. → base resistor → 2N2222 base
constexpr int PIN_LED_R = 4;    // left header (GPIO2 skipped: boot strapping pin)
constexpr int PIN_LED_G = 3;
constexpr int PIN_LED_B = 1;
constexpr uint8_t LED_R_MAX = 60, LED_G_MAX = 255, LED_B_MAX = 255;

// ---------- Behaviour ----------
constexpr float    DEFAULT_SETPOINT   = 35.0f;   // °C: low enough for a warm hand to trigger on stage
constexpr float    DEFAULT_HYSTERESIS = 2.0f;    // °C: clears at setpoint − hysteresis
constexpr uint8_t  DEFAULT_DELAY_S    = 3;       // seconds above setpoint before the alarm
constexpr uint32_t SENSOR_TIMEOUT_MS  = 6000;    // no packet from Node 1 for this long = sensor lost
constexpr uint32_t MAX_ON_MS          = 120000;  // siren auto-silences after 2 min (counts as an ack)
constexpr uint32_t TEST_MS            = 2000;    // siren test length
constexpr uint32_t HOLD_FOR_TEST_MS   = 2000;
constexpr uint32_t DEBOUNCE_MS        = 30;
constexpr uint32_t NOTIFY_EVERY_MS    = 1000;

enum AlarmState : uint8_t { ST_NORMAL = 0, ST_PENDING = 1, ST_ALARM = 2, ST_ACKED = 3 };
const char *STATE_NAMES[] = {"NORMAL", "PENDING", "ALARM", "ACKNOWLEDGED"};

// Config (persisted in flash)
Preferences prefs;
float setpoint = DEFAULT_SETPOINT, hysteresis = DEFAULT_HYSTERESIS;
uint8_t delayS = DEFAULT_DELAY_S;

// Alarm engine
AlarmState state = ST_NORMAL;
uint32_t aboveSince = 0, alarmSince = 0, testUntil = 0;
bool relayOn = false;

// Latest from Node 1 (over UDP, read in loop)
portMUX_TYPE mux = portMUX_INITIALIZER_UNLOCKED;   // guards pendingCmd (written by BLE)
WiFiUDP udp;
uint32_t lastPacketAt = 0, rxOk = 0, rxRejected = 0;
int16_t centiC = fc26::NO_READING;
uint8_t sensorFault = fc26::FAULT_NONE;
bool sensorOnline = false;

// BLE
BLECharacteristic *stateChr = nullptr;
volatile bool bleConnected = false;
char pendingCmd[24] = {0};
bool stateDirty = true;

// ---------- Outputs ----------
void led(uint8_t r, uint8_t g, uint8_t b) {
  analogWrite(PIN_LED_R, 255 - r * LED_R_MAX / 255);
  analogWrite(PIN_LED_G, 255 - g * LED_G_MAX / 255);
  analogWrite(PIN_LED_B, 255 - b * LED_B_MAX / 255);
}

void applyRelay() {
  const bool want = state == ST_ALARM || millis() < testUntil;
  if (want == relayOn) return;
  relayOn = want;
  digitalWrite(PIN_RELAY, want ? HIGH : LOW);
  Serial.printf("[relay] %s\n", want ? "ON" : "OFF");
  stateDirty = true;
}

void setState(AlarmState next, const char *why) {
  if (next == state) return;
  Serial.printf("[alarm] %s → %s (%s)\n", STATE_NAMES[state], STATE_NAMES[next], why);
  state = next;
  if (next == ST_ALARM) alarmSince = millis();
  stateDirty = true;
}

// ---------- Alarm engine (same rules as the Flutter app's AlarmEngine) ----------
void evaluate(float t, uint32_t now) {
  switch (state) {
    case ST_NORMAL:
      if (t >= setpoint) { aboveSince = now; setState(ST_PENDING, "above setpoint"); }
      break;
    case ST_PENDING:
      if (t < setpoint) setState(ST_NORMAL, "dropped below setpoint");
      break;
    case ST_ALARM:
    case ST_ACKED:
      if (t <= setpoint - hysteresis) setState(ST_NORMAL, "cooled down");
      break;
  }
  if (state == ST_PENDING && now - aboveSince >= delayS * 1000UL) setState(ST_ALARM, "above setpoint for the delay");
}

void acknowledge(const char *who) {
  if (state == ST_ALARM) setState(ST_ACKED, who);
  if (testUntil) { testUntil = 0; stateDirty = true; }
}

void startTest(const char *who) {
  if (state == ST_ALARM) return;   // already sounding
  Serial.printf("[test] siren test (%s)\n", who);
  testUntil = millis() + TEST_MS;
  stateDirty = true;
}

// ---------- Wi-Fi access point + UDP ----------
void onWifiEvent(arduino_event_id_t event, arduino_event_info_t) {
  if (event == ARDUINO_EVENT_WIFI_AP_STACONNECTED) Serial.println("[wifi] a device joined FC26-NET");
  if (event == ARDUINO_EVENT_WIFI_AP_STADISCONNECTED) Serial.println("[wifi] a device left FC26-NET");
}

void setupWifi() {
  WiFi.onEvent(onWifiEvent);
  WiFi.mode(WIFI_AP);
  // Hidden = 0, max 2 devices (Node 1 + a laptop for debugging).
  const bool ok = WiFi.softAP(fc26::WIFI_SSID, fc26::WIFI_PASS, fc26::WIFI_CHANNEL, 0, 2);
  WiFi.setTxPower(FC26_WIFI_TX_POWER);
  udp.begin(fc26::UDP_PORT);
  Serial.printf("[wifi] access point %s %s on channel %u, IP %s, UDP port %u\n", fc26::WIFI_SSID,
                ok ? "up" : "FAILED", fc26::WIFI_CHANNEL, WiFi.softAPIP().toString().c_str(), fc26::UDP_PORT);
}

// Reads every waiting packet; returns true with the newest valid one in `out`.
bool receivePacket(fc26::TempPacket &out) {
  bool got = false;
  uint8_t buf[32];
  for (int size = udp.parsePacket(); size > 0; size = udp.parsePacket()) {
    const int len = udp.read(buf, sizeof(buf));
    const auto *p = (const fc26::TempPacket *)buf;
    if (len != (int)sizeof(fc26::TempPacket) || memcmp(p->magic, "FC26", 4) || p->version != fc26::VERSION ||
        p->networkId != fc26::NETWORK_ID) {
      if (rxRejected++ % 10 == 0) Serial.printf("[wifi] rejected a %d-byte packet (not FC26 v%u, network %u)\n",
                                                len, fc26::VERSION, fc26::NETWORK_ID);
      continue;
    }
    memcpy(&out, buf, sizeof(out));
    rxOk++;
    got = true;
  }
  return got;
}

void handleSensor() {
  fc26::TempPacket p = {};
  const bool fresh = receivePacket(p);

  const uint32_t now = millis();
  if (fresh) {
    lastPacketAt = now;
    if (!sensorOnline) Serial.println("[sensor] Node 1 online");
    sensorOnline = true;
    sensorFault = p.fault;
    centiC = p.centiC;
    stateDirty = true;
    if (p.centiC != fc26::NO_READING) evaluate(p.centiC / 100.0f, now);
  }
  const bool lost = sensorOnline && now - lastPacketAt > SENSOR_TIMEOUT_MS;
  const bool noData = lost || (fresh && p.centiC == fc26::NO_READING);
  if (lost) {
    sensorOnline = false;
    centiC = fc26::NO_READING;
    Serial.println("[sensor] Node 1 lost");
  }
  // No trustworthy temperature: stand down. (A real plant might sound the alarm instead.)
  if (noData) setState(ST_NORMAL, lost ? "sensor lost" : "sensor fault");
}

void logLinkStats() {
  static uint32_t last = 0;
  if (millis() - last < 10000) return;
  last = millis();
  Serial.printf("[wifi] %u device(s) on FC26-NET, %lu packets from Node 1, %lu rejected, sensor %s\n",
                WiFi.softAPgetStationNum(), (unsigned long)rxOk, (unsigned long)rxRejected,
                sensorOnline ? "online" : "waiting");
}

void handleMaxOn() {
  if (state == ST_ALARM && MAX_ON_MS && millis() - alarmSince >= MAX_ON_MS) setState(ST_ACKED, "max on-time reached");
}

// ---------- TTP223 ----------
void handleTouch() {
  static bool stable = false, last = false, testFired = false;
  static uint32_t changedAt = 0, pressedAt = 0;
  const bool raw = digitalRead(PIN_TOUCH) == HIGH;
  if (raw != last) { last = raw; changedAt = millis(); }
  if (millis() - changedAt < DEBOUNCE_MS || raw == stable) {
    if (stable && !testFired && millis() - pressedAt >= HOLD_FOR_TEST_MS && (state == ST_NORMAL || state == ST_PENDING)) {
      testFired = true;
      startTest("touch hold");
    }
    return;
  }
  stable = raw;
  if (stable) {                       // pressed
    pressedAt = millis();
    testFired = false;
    if (state == ST_ALARM || testUntil) { acknowledge("touch"); testFired = true; }
  }
}

// ---------- BLE ----------
class ServerCallbacks : public BLEServerCallbacks {
  void onConnect(BLEServer *) override { bleConnected = true; }
  void onDisconnect(BLEServer *) override {
    bleConnected = false;
    BLEDevice::startAdvertising();
  }
};

class CommandCallbacks : public BLECharacteristicCallbacks {
  void onWrite(BLECharacteristic *c) override {
    String v = c->getValue();
    portENTER_CRITICAL(&mux);
    strlcpy(pendingCmd, v.c_str(), sizeof(pendingCmd));
    portEXIT_CRITICAL(&mux);
  }
};

void setupBle() {
  BLEDevice::init("FC26-SIREN");
  BLEServer *server = BLEDevice::createServer();
  server->setCallbacks(new ServerCallbacks());
  BLEService *svc = server->createService(FC26_SIREN_SERVICE);
  stateChr = svc->createCharacteristic(
      FC26_SIREN_STATE, BLECharacteristic::PROPERTY_READ | BLECharacteristic::PROPERTY_NOTIFY);
  BLECharacteristic *cmd = svc->createCharacteristic(
      FC26_SIREN_COMMAND, BLECharacteristic::PROPERTY_WRITE | BLECharacteristic::PROPERTY_WRITE_NR);
  cmd->setCallbacks(new CommandCallbacks());
  svc->start();
  BLEAdvertising *adv = BLEDevice::getAdvertising();
  adv->addServiceUUID(FC26_SIREN_SERVICE);
  adv->setScanResponse(true);
  BLEDevice::startAdvertising();
}

void saveConfig() {
  prefs.putFloat("sp", setpoint);
  prefs.putFloat("hy", hysteresis);
  prefs.putUChar("dl", delayS);
}

void handleCommand() {
  char cmd[sizeof(pendingCmd)];
  portENTER_CRITICAL(&mux);
  strlcpy(cmd, pendingCmd, sizeof(cmd));
  pendingCmd[0] = 0;
  portEXIT_CRITICAL(&mux);
  if (!cmd[0]) return;
  Serial.printf("[ble] command '%s'\n", cmd);

  if (!strcmp(cmd, "ACK") || !strcmp(cmd, "STOP")) {
    acknowledge("ble");
  } else if (!strcmp(cmd, "TEST")) {
    startTest("ble");
  } else if (!strncmp(cmd, "CFG=", 4)) {   // CFG=<setpoint>,<hysteresis>,<delay s>
    float sp, hy;
    int dl;
    if (sscanf(cmd + 4, "%f,%f,%d", &sp, &hy, &dl) == 3 && sp >= 0 && sp <= 150 && hy >= 0.1f && hy <= 20 &&
        dl >= 0 && dl <= 60) {
      setpoint = sp;
      hysteresis = hy;
      delayS = (uint8_t)dl;
      saveConfig();
      Serial.printf("[cfg] setpoint %.2f, hysteresis %.2f, delay %u s\n", setpoint, hysteresis, delayS);
      // Re-check against the new limits on the next reading.
      if (state == ST_PENDING) setState(ST_NORMAL, "config changed");
    } else {
      Serial.println("[cfg] rejected: out of range");
    }
  } else {
    Serial.println("[ble] unknown command");
  }
  stateDirty = true;
}

// State packet, 10 bytes little-endian (see README):
// int16 centi-°C | uint8 state | uint8 flags | int16 centi setpoint | uint16 centi hysteresis | uint8 delay s | uint8 seq
void notifyState() {
  static uint32_t lastNotify = 0;
  static uint8_t seq = 0;
  if (!stateDirty && millis() - lastNotify < NOTIFY_EVERY_MS) return;
  lastNotify = millis();
  stateDirty = false;

  const uint8_t flags = (relayOn ? 1 : 0) | (sensorOnline ? 2 : 0) | (testUntil ? 4 : 0) |
                        (sensorFault != fc26::FAULT_NONE ? 8 : 0);
  const int16_t sp = (int16_t)lroundf(setpoint * 100);
  const uint16_t hy = (uint16_t)lroundf(hysteresis * 100);
  uint8_t b[10];
  memcpy(b, &centiC, 2);
  b[2] = state;
  b[3] = flags;
  memcpy(b + 4, &sp, 2);
  memcpy(b + 6, &hy, 2);
  b[8] = delayS;
  b[9] = seq++;
  stateChr->setValue(b, sizeof(b));
  if (bleConnected) stateChr->notify();
}

void updateLed() {
  const uint32_t t = millis();
  if (relayOn)                led((t / 100) % 2 ? 255 : 0, 0, 0);    // siren: fast red
  else if (state == ST_ACKED)    led(255, 0, 0);                          // silenced, still hot: solid red
  else if (state == ST_PENDING)  led((t / 400) % 2 ? 255 : 0, 0, 0);     // rising: slow red
  else if (!sensorOnline || centiC == fc26::NO_READING)
                              led(0, 0, (t / 500) % 2 ? 255 : 0);     // waiting for Node 1: slow blue
  else                        led(0, 255, 0);                          // all good: green
}

// ---------- Arduino ----------
void setup() {
  // Relay OFF before anything else.
  digitalWrite(PIN_RELAY, LOW);
  pinMode(PIN_RELAY, OUTPUT);
  digitalWrite(PIN_RELAY, LOW);

  Serial.begin(115200);
  pinMode(PIN_TOUCH, INPUT);
  pinMode(PIN_LED_R, OUTPUT);
  pinMode(PIN_LED_G, OUTPUT);
  pinMode(PIN_LED_B, OUTPUT);
  led(255, 0, 0); delay(250);
  led(0, 255, 0); delay(250);
  led(0, 0, 255); delay(250);
  led(0, 0, 0);

  prefs.begin("fc26n2");
  setpoint = prefs.getFloat("sp", DEFAULT_SETPOINT);
  hysteresis = prefs.getFloat("hy", DEFAULT_HYSTERESIS);
  delayS = prefs.getUChar("dl", DEFAULT_DELAY_S);
  Serial.printf("\nNode 2 (siren) starting. Relay OFF. Setpoint %.2f °C, hysteresis %.2f, delay %u s\n",
                setpoint, hysteresis, delayS);

  setupWifi();
  setupBle();
}

void loop() {
  handleSensor();
  logLinkStats();
  handleCommand();
  handleTouch();
  handleMaxOn();
  if (testUntil && millis() >= testUntil) { testUntil = 0; stateDirty = true; }
  applyRelay();
  notifyState();
  updateLed();
}

namespace fc26 {

// ---------- Wi-Fi (node 1 → node 2, no router: Node 2 is the access point) ----------
// Node 2 creates the FC26-NET network; Node 1 joins it and sends one UDP packet a second to
// Node 2's address. If two of these kits are in the same room, give each kit its own SSID
// and NETWORK_ID. The password only keeps strangers' phones off the network.

// ESP32-C3 Super Mini boards have a poorly matched antenna: at full power (19.5 dBm) their
// Wi-Fi often doesn't get out at all. 8.5 dBm is the usual fix and plenty for a table-top demo.
#define FC26_WIFI_TX_POWER WIFI_POWER_8_5dBm
constexpr uint8_t  NETWORK_ID   = 26;
constexpr uint8_t  VERSION      = 1;
constexpr int16_t  NO_READING   = INT16_MIN;   // centi-°C value meaning "no valid reading"

enum Fault : uint8_t {
  FAULT_NONE        = 0,
  FAULT_ADC_MISSING = 1,   // ADS1115 not answering on I2C
  FAULT_OPEN        = 2,   // probe or a wire disconnected
  FAULT_SHORT       = 3,   // probe wires touching
  FAULT_RANGE       = 4,   // resistance outside -200…850 °C
};

struct __attribute__((packed)) TempPacket {   // 10 bytes, one UDP packet a second
  char     magic[4];    // "FC26"
  uint8_t  version;     // VERSION
  uint8_t  networkId;   // NETWORK_ID
  uint8_t  seq;         // increments every packet
  uint8_t  fault;       // Fault
  int16_t  centiC;      // °C × 100, or NO_READING
};
